# Capturas de tela para o portfólio

A imagem `preview-dashboard.svg` é uma **prévia ilustrativa vetorial**, baseada na interface demonstrativa visualizada durante o desenvolvimento. Ela não é uma captura da versão mais recente.

Para registrar screenshots reais, execute localmente a versão atual e capture:

1. **Visão geral:** dashboard com os KPIs e filtros visíveis.
2. **Evolução mensal:** seção de histórico de seis meses, com o período selecionado.
3. **Gestão de metas:** cadastro ou listagem com atualização do realizado.
4. **Layout responsivo:** uma visualização em janela estreita ou modo mobile.

Nomeie os arquivos como `dashboard.png`, `historico.png`, `metas.png` e `mobile.png`, colocando-os em `docs/screenshots/`. Atualize o README para exibir a captura principal ao lado da prévia ilustrativa, quando estiver pronta.

**Antes de capturar:** use apenas os dados fictícios padrão, não deixe notificações ou informações pessoais na tela, e evite o cursor ou aplicações sobrepostas.

Dica para Windows: `Win + Shift + S` abre a ferramenta de captura. Salve a imagem PNG. Não inclua imagens de sistemas internos ou corporativos.
